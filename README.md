# NRW Frost-Risk Shiny App

Mobile-first Shiny app accompanying the NRW-Agrartag 2026 poster, for exploring precomputed frost-risk maps and related geospatial layers for North Rhine-Westphalia.

The app provides an interactive map view of frost-risk outputs for apple production, alongside selected terrain, climate, and reference layers. It is intended as a lightweight public demonstrator for visualizing existing model results, not as a tool for calculating frost risk or running the underlying phenology and climate-processing workflows.

The displayed layers are based on prepared geospatial data and are served through a simple Shiny interface optimized for mobile and desktop use.
